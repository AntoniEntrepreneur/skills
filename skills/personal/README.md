# Personal

Skills I wrote myself, not part of Matt's upstream, not promoted in the plugin.

- **[cleanup](./cleanup/SKILL.md)**: Delete branches, worktrees and stashes whose work is on main, and Sandcastle labels whose work is closed; report work that never landed.
- **[explain](./explain/SKILL.md)**: Explain a programming term, or narrate a whole situation, in plain English, and log jargon to a personal dev glossary.
- **[implement-iso](./implement-iso/SKILL.md)**: Implement a piece of work in an isolated worktree and branch, then push and open a PR.
- **[mediumrare](./mediumrare/SKILL.md)**: Unpack the grilling questions you're stuck on, in plain English, every option kept, trade-offs spelled out.
- **[setup-antoni-skills](./setup-antoni-skills/SKILL.md)**: Set up a repo's `docs/agents/` layer and the `AGENTS.md` pointers to it, or converge an older setup.
- **[setup-sandcastle](./setup-sandcastle/SKILL.md)**: Install the Sandcastle loop from [sandcastle-loop](https://github.com/AntoniEntrepreneur/sandcastle-loop) into a project, or update it.
- **[quiz](./quiz/SKILL.md)**: Feynman-style quiz on your personal dev glossary, to promote a term from introduced to known.
